# CactusCogs

Shitty redbot cogs. Like, really bad.

I borrowed a lot from these excellent folks:
[aikaterna](https://github.com/aikaterna),
[TrustyJAID](https://github.com/TrustyJAID)

there's also ai slop in here now because it's 2026 and you can't get away from it. you've been warned.

| Cog | Function |
| --- | --- |
| `anonymouspoll` | Runs anonymous button polls; voters' choices are stored only while each poll is open. |
| `hockeyschedule` | Updates a configured channel topic with the next game for a selected NHL team. |
| `imageresponder` | Responds to configured triggers with a random image. |
| `invitechecker` | Logs which invite was used when a member joins. |
| `secretpolice` | Fines or jails members who use configured words such as “uwu” or “owo.” |
| `sentientpants` | Experimental conversation-mode cog with an unfinished Stable Diffusion command. |
| `stablediff` | Generates images through a self-hosted Stable Diffusion (AUTOMATIC1111) web UI. |
| `stonks` | Work-in-progress stock market simulator; currently fetches stock quotes using RapidAPI. |
| `thecounter` | Tracks time since a configured banned word was last said and times out repeat offenders. |
| `vibecheck` | Analyzes a member's recent messages with IBM Watson Tone Analyzer and reports their vibe. (do we really even need this with LLMs?) |
